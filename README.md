# 드래곤빌리지3 레이드 자동 매크로

LDPlayer 9 환경에서 파이썬(OpenCV, ADB)을 이용해 드래곤빌리지3 레이드를 자동으로 반복하는 매크로 프로그램입니다. 피로도 부족 시 회복제를 자동으로 사용하며, 종료된 레이드 방을 스스로 인식해 탈출하는 로직이 포함되어 있습니다.

## 필수 환경 설정
- 앱플레이어: LDPlayer 9
- 해상도: 모바일 모드 540x960
- 앱플레이어 설정: 톱니바퀴 메뉴 -> 기타 설정 -> ADB 디버깅 -> '로컬 디버깅 열기'로 설정 후 앱플레이어 재시작
- 파이썬 버전: Python 3.15.1

## 폴더 구조
프로젝트를 다운로드하면 아래와 같은 구조로 배치되어 있어야 합니다.
- macro.py (메인 실행 파일)
- requirements.txt (필요한 라이브러리 목록)
- README.md (설명서)
- images/ (버튼 인식용 캡처 이미지 9장이 들어있는 폴더)

## 설치 및 실행 방법

1. 라이브러리 설치
명령 프롬프트(cmd)를 열고 다운로드한 폴더 경로로 이동한 뒤, 아래 명령어를 입력해 필요한 패키지를 설치합니다.
`pip install -r requirements.txt`

2. 게임 준비
LDPlayer를 실행하고 드래곤빌리지3를 켜서 레이드 대기실이나 로비 화면에 둡니다.

3. 매크로 실행
명령 프롬프트에서 아래 명령어를 입력하여 프로그램을 시작합니다.
`python macro.py`
